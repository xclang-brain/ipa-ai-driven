# 引き継ぎ

2026-11-22 時点の状態を、作業する環境を切り替えるためにまとめた。次に作業する人と AI は、[process.md](process.md) を読んだあとに、この文書を読む。

## 1. これまでの経緯

1. 依頼者の困りごとは、AI 駆動開発のためのナレッジ管理である。既存ドキュメントのほとんどが Word と Excel で、GitHub Copilot が内容を理解できない。既存の変換ツールでは、レイアウトが崩れ、図形や画像が抜ける。
2. IPA のハンドブックの12工程に沿って、目的の確認から進めた。依頼者へのヒアリングは2回行った。
3. 公開されている設計書で検証し、手段を決めた。文字と表はプログラムで取り出し、図だけを Copilot が Mermaid に書き起こし、プログラムと AI で照合する。依頼者は 2026-11-22 に合意した。
4. 初回の範囲（Excel の文書1つ）について、移行ツール `docmig` と Copilot CLI 用の定義を作った。
5. 開発環境には Copilot CLI と Office がなかった。AI の段階は、開発環境の AI が定義に従って代行し、手順が通しで成り立つことを確かめた。

詳しくは `docs/01` から `docs/07` の各文書にある。

## 3. 次に行うこと

Copilot CLI が使える環境で、上から順に行う。手順は [runbook.md](runbook.md) にある。結果は [process.md](process.md) の 3.5 に従って記録する。

| 順番 | 行うこと | 確かめること |
|---|---|---|
| 1 | 準備（`pip install -e ".[excel,dev]"`、`pytest`） | Windows でテストが合格するか（NFR-002） |
| 2 | サンプル文書の下書きを、新しいフォルダに作る | Excel を使った描画が動くか。画像が原本と合っているか（V-2、FR-006）。開発環境で代用した LibreOffice は、矢印1本を原本と違う向きに描いた |
| 3 | 図を1つ、Copilot CLI で書き起こす | 画像を渡せるか。定義のとおりに動くか（V-1、FR-014） |
| 4 | 検査し、確認するエージェントを動かす | 食い違いの報告と、状態の変更が、定義のとおりか（FR-015） |
| 5 | 移行後の文書について Copilot に質問する | 正しく答えるか。由来を示すか（S-3、FR-016） |
| 6 | 依頼者の実際の文書を1つ移行する | ファームウェアの文書で通用するか（V-3）。人の作業時間（S-4） |

`migrated/screen-transition/` は開発環境での試行の結果である。手順2では、これを上書きせず、別のフォルダ（例 `migrated/trial-01`）に作る。

## 5. 初回の範囲に含めていないもの

次のものは、要求としては合意済みだが、まだ要件にしていない。着手するときは [process.md](process.md) の 3.1 か 3.4 から始める。

| 対象 | 関係する要求 | 分かっていること |
|---|---|---|
| Word の文書 | REQ-001、REQ-003 | サンプルの Word 文書では、図形がすべて旧形式（VML）で保存されていた。新旧両方の形式への対応が要る |
| 貼り付け画像の内容の読み取り | REQ-004 | 画像の中の文字は、正解がファイルの中にないため、プログラムで照合できない。OCR と AI の両方に読ませて食い違いを見る方法を候補にしている。OCR の採否は未定（[要求分析](04-analysis.md) 4章） |

| 100ページ、100文書の規模 | REQ-018 | 確かめていない |
